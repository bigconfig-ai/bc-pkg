# Goal

A self-contained `index.html` for `@bigconfig/bb`, styled like
`/Users/amiorin/code/personal/big-config/main/index.html` (sidebar manual),
but a **full manual** and **fully offline**.

# Resolved decisions

- **Scope:** full manual mirroring the reference's depth (many sections,
  changelog, glossary), not a minimal landing.
- **Self-contained = fully offline:** single file, all CSS/JS inline, **no
  external requests**, **no Google Analytics**, **no CDN highlight.js**. Code
  blocks keep the GitHub-style frame but no token coloring. Inline JS only
  (scroll-spy + smooth scroll + active sidebar), same as the reference's
  bottom script.
- **Location:** `index.html` at the repo root. **Not** added to
  `package.json` `files` (kept out of the npm tarball).
- **Branding:** reuse the BigConfig identity — `← BigConfig` brand back-link,
  maintainer footer "Alberto Miorin (albertomiorin.com)", generated date
  2026-05-17. Favicon reused but **inlined as a data-URI SVG** (to stay
  offline; reconciles the offline vs favicon tension).
- **Content source:** derived from the current `bin/bb.js` + `README.md` +
  git history (accurate to v0.2.0 behavior).

# Page structure (sidebar groups → sections)

- **Start:** Overview · Why @bigconfig/bb · Installation & usage (npx) ·

# Required examples (Examples section)

1. Local bootstrap:
   `BB_EDN_REPO=bigconfig-ai/once npx @bigconfig/bb@latest tasks`
2. Docker, verbatim:
   `docker run -it --rm -u node -w /home/node node:24 npx @bigconfig/bb@latest tasks`
3. Docker + repo + task:
   `docker run -it --rm -u node -w /home/node -e BB_EDN_REPO=bigconfig-ai/once node:24 npx @bigconfig/bb@latest validate`
4. `BB_EDN_REPO` explainer: what it does (bb.edn bootstrap + `:local/root`
   strip + git-dep injection), shown in both local and Docker forms.

# Content to document (accurate to v0.2.0)

- Pinned versions: babashka `1.12.196`, Temurin `21`, rewrite-edn `0.5.9`;
  overridable via `BB_VERSION` / `JDK_VERSION` / `REWRITE_EDN_VERSION`.
- Env vars: `BB_VERSION`, `JDK_VERSION`, `BB_EDN_REPO`, `GITHUB_TOKEN`,
  `REWRITE_EDN_VERSION`.
- Platforms: macOS arm64/x64, Linux x64/arm64 (arm64 = static build),
  Windows x64; Windows arm64 unsupported.
- Cache: `$XDG_CACHE_HOME`/`~/.cache`/`%LOCALAPPDATA%` → `bigconfig-bb/`;
  atomic temp+rename install (race-safe); lazy on first run.
- JDK env (`JAVA_HOME`/`PATH`) scoped to the bb subprocess only.
- Git: Linux-only, skipped if present, package-manager + sudo.
- bb.edn bootstrap: GitHub API, default-branch HEAD pin, `GITHUB_TOKEN`,
  rewrite-edn (comment-preserving); first run also fetches Clojure tools.
- Changelog: 0.1.0 launcher (babashka/JDK/git); 0.2.0 bb.edn bootstrap +
  `:local/root` strip.
