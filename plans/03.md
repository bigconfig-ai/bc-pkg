# Goal

When a `bb.edn` is bootstrapped from GitHub (the `ensureBbEdn` step, plans/02),
`:local/root` coordinates point at paths that don't exist on the user's
machine. Remove every dependency that uses one.

# Example

`https://raw.githubusercontent.com/bigconfig-ai/once/refs/heads/main/bb.edn`:

```clojure
{:deps {io.github.amiorin/once {:local/root "."}}
 :tasks {:requires ([io.github.amiorin.once.describe :as describe] ...) ...}}
```

The single dep is `{:local/root "."}` and must be removed. Net result after
the full step (removal + plans/02 injection, with `BB_EDN_REPO=owner/once`):

```clojure
{:deps {io.github.<owner>/once {:git/sha "<sha>"}}
 :tasks {:requires (...) ...}}
```

# Resolved decisions

- **Part of `ensureBbEdn`.** Applied to the downloaded EDN, in the same
  `borkdude/rewrite-edn` script — no extra process or downloads.
- **Granularity:** remove the **entire dependency entry** (key + coord) when
  its effective coordinate is a map containing `:local/root`.
- **Scope:** clean the top-level `:deps` map **and** every task's
  `:extra-deps` map under `:tasks`.
- **Detection uses the effective coordinate** (`rewrite-edn` `sexpr`, which
  respects `#_` discard). So
  `io.github.borkdude/quickdoc #_{:local/root ".."} {:git/sha …}` is **kept**
  (its active coord is the git map), while `{:local/root "."}` is removed.
- **Order:** strip `:local/root` deps **first**, then inject the plans/02
  `io.github.<owner>/<project> {:git/sha …}` dep, so injection wins on any
  key collision. An empty `:deps {}` after removal is fine (it then receives
  the injected dep).

# Flow (inside ensureBbEdn's rewrite script)

1. Parse the downloaded EDN.
2. For the `:deps` map: drop every entry whose effective coord map contains
   `:local/root`.
3. For each task under `:tasks` that has an `:extra-deps` map: drop every
   entry in it whose effective coord map contains `:local/root`.
4. Inject `io.github.<owner>/<project> {:git/sha "<sha>"}` into `:deps`
   (plans/02 behaviour, unchanged).
5. Write the result to `./bb.edn`, preserving comments/formatting.

# Notes / edge cases

- The removed dep often supplies namespaces still listed in `:tasks/:requires`
  (e.g. `io.github.amiorin.once.*`). After removal those resolve only via the
  injected git dep — and only if that repo's own `deps.edn`/`bb.edn` exposes
  the corresponding source paths. This is the intended "local self-ref →
  git self-ref" swap; it is the bootstrapped repo's responsibility.
- Removed-dep key and injected-dep key can differ (`io.github.amiorin/once`
  vs `io.github.<owner>/once`); both operations are independent.
- Missing `:deps` or `:tasks` → those steps are simply skipped.
