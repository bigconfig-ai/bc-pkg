# Goal
The bb.edn in the root of the project works with npm-bb

# Requirements
- if Dockerfile doesn't exists it is downloaded from the GitHub repo bigconfig-ai/npm-bb
- "BB_EDN_REPO=bigconfig-ai/npm-bb npx @bigconfig/bb shell" works in an empty directory

# Resolved decisions
- Download the missing Dockerfile to `./Dockerfile` in the current/project directory.
- Use the same GitHub SHA that `BB_EDN_REPO` pinned in the bootstrapped `bb.edn`.
- Check/download the Dockerfile whenever task config is loaded.
- `~/.pi/agent/auth.json` and `~/.pi/agent/settings.json` are optional; skip them if missing.
