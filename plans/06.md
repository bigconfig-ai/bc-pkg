# Goal
Never forward owner/repo but compare it with the bb.edn if there is a bb.edn

# Requirements
- inject the key :repo "owner/repo" when the bb.edn doesn't exist and it is created
- use the key :repo from bb.edn to make sure that the CLI owner/repo is the same of the bb.edn
- exit with error if the bb.edn exists, the :repo of the bb.edn is different from the owner/repo of the CLI
- if the bb.edn exists then the CLI owner/repo can be skipped
