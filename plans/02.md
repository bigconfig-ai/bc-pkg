# Goal

When the cwd has no `bb.edn`, bootstrap one from a GitHub repo (named by the
first `owner/project` CLI argument) before invoking `bb`, adding that repo
itself as a pinned git dependency.

# Resolved decisions

- **Trigger:** first CLI argument `owner/project`. Omitted → skip this step
  entirely and invoke `bb` normally (req 9).
- **Trigger:** only when there is no `./bb.edn` in the cwd (req 1). If present,
  skip.
- **Ref/SHA:** the CLI repo is `owner/project` only (no ref). Resolve the
  repo's **default-branch HEAD commit at download time** and pin to that sha.
- **Fetch:** GitHub API.
  1. `GET /repos/{owner}/{project}/commits?per_page=1` → latest commit sha
     (repo missing / inaccessible → fatal error).
  2. `GET /repos/{owner}/{project}/contents/bb.edn?ref={sha}` with
     `Accept: application/vnd.github.raw` → file contents.
     **404 → fatal error: repo has no `bb.edn`** (req 7).
- **Auth:** if `GITHUB_TOKEN` is set, send `Authorization: Bearer …`
  (enables private repos + lifts the 60 req/hr unauthenticated limit).
  Public repos work with no token.
- **Injection:** use **`borkdude/rewrite-edn`** (comment/format preserving),
  run through the already-installed `bb` (`babashka.deps/add-deps`, pinned
  mvn version). Add to `:deps`:
  `io.github.<owner>/<project> {:git/sha "<sha>"}`. Create `:deps` if absent.
  Leave any existing `:tasks`/`:requires` untouched.
- **Output:** write the rewritten EDN to `./bb.edn` (cwd = project root),
  then proceed to invoke `bb`.
- **Step order:** ensureBabashka → ensureJdk → ensureGit (Linux) →
  **ensureBbEdn** → run `bb`. (Runs after bb is installed because the rewrite
  is performed by bb.)
- **Failures** (network, repo or `bb.edn` missing, rewrite error) are fatal
  with actionable messages, consistent with the other bootstrap steps.

# Flow

1. `./bb.edn` exists → skip. First-argument repo omitted → skip.
2. Parse `owner/project`; resolve default-branch HEAD sha (req 2 satisfied via
   CLI arg; 404/empty → fatal).
3. Fetch `bb.edn` at that sha (404 → fatal "no bb.edn in repo", req 7).
4. Run a bb script using `borkdude/rewrite-edn`: parse fetched content,
   `assoc-in [:deps 'io.github.<owner>/<project>] {:git/sha "<sha>"}`,
   write `./bb.edn` preserving formatting/comments (req 8).
5. Continue: invoke `bb` with the user's args.

# Notes / edge cases

- `rewrite-edn` pinned to `0.5.9` (latest on Clojars at implementation),
  overridable via `REWRITE_EDN_VERSION`. First use downloads it (and the
  Clojure tools) via babashka deps — cached afterward.
- Symbol `io.github.<owner>/<project>`: owner/project containing characters
  invalid in Clojure symbols is an edge case — documented limitation.
- Self-referential by design: the downloaded repo's `bb.edn` typically has
  tasks whose `:requires` resolve via this added git dep.
